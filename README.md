# 🏎️ F1 Čtverečkovaná Velká cena

Digitální adaptace legendární papírové hry **Vektorové závody (Racetrack)** zasazená do autentického prostředí Formule 1. Hra kombinuje retro nostalgii tahových her na čtverečkovaném papíře s reálnou vektorovou setrvačností monopostů a moderním uživatelským rozhraním v JavaFX.

---

## 🎮 Herní režimy
* **Trénink (Practice):** Seznámení se s tratí a pilování ideální závodní stopy.
* **Kvalifikace (Qualifying):** Boj o nejrychlejší kolo a pole position s funkcí ghost car (průjezd skrze ostatní vozy).
* **Závod (Race):** Ostrý souboj tělo na tělo s plnou detekcí kolizí a traťovými incidenty.

## 🏁 Funkce a vlastnosti
* **Vektorový model pohybu:** Autentická setrvačnost monopostu — hráč volí zrychlení $\pm 1$ a musí plánovat průjezdy šikanami několik tahů dopředu.
* **Výběr týmů a monopostů:** Red Bull, Ferrari, McLaren a další s vlastní barevnou identitou.
* **Závodní okruhy:** Široký výběr světových tratí (Red Bull Ring, Interlagos, Monza, Spa a další).
* **Oficiální vizuál:** Závodní typografie F1 a telemetrie sektorů.

---

## 🛠️ Technologie
* **Jazyk:** Java
* **Grafické rozhraní:** JavaFX
* **Build nástroj:** Apache Maven
